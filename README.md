### Goal Quest

Goal Quest is a personal web app I’m building to track goals and visualize progress through an evolving avatar.
The project is part of my journey to rebuild strong coding foundations and practice full-stack development using modern tools.

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Project Goals

Build a clean, goal-tracking dashboard from scratch
Learn full-stack development with Next.js, TypeScript, and Prisma
Implement an XP and avatar system that grows as goals are achieved
Practice professional project setup, Git workflow, and clean code structure

## Tech Stack

Frontend / Framework: Next.js 14 + TypeScript
Styling: Tailwind CSS
Database: Prisma + SQLite (for development)
Auth (later): NextAuth.js

## Current Status

## How to Run Locally

1️⃣ Clone the repository
git clone https://github.com/myriambenkiran/goal-quest.git
cd goal-quest
2️⃣ Install dependencies
npm install
3️⃣ Run the development server
npm run dev
Now open http://localhost:3000 to see it in your browser.
You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
